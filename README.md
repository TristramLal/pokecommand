# PokéCommand

An installable, offline-capable Pokémon GO companion PWA.

## Features
- Dashboard with explicitly dated November 2026 event snapshot (not live).
- Shiny hunt counters, history, undo and editable totals. Shadow Tornadus starts at 9 raids / 1 shiny.
- Editable Pokémon collection with IVs, moves, Candy and Max Move fields.
- Preliminary raid team suggestions. These are not battle simulations.
- Community meetup planning.
- Local storage and JSON export/restore.

## Publish
In GitHub Settings → Pages, select Deploy from a branch → main → /(root) → Save. Open https://tristramlal.github.io/pokecommand/ in iPhone Safari and use Share → Add to Home Screen.

## Privacy
Data stays in browser localStorage, not GitHub. Export backups regularly. Clearing website data can erase local records. No login, OCR, push notifications, live event API or cloud sync is included.

This is an independent fan-made utility and is not affiliated with Niantic or The Pokémon Company.
